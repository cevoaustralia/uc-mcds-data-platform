# Mock Data Generator

Generate mock Callista data for local development testing.

## Files

- `generators/` - Python scripts to generate 6 Callista tables
- `generate_all.py` - Generate full dataset (100 students)
- `upload_to_s3.py` - Upload to Cevo AWS S3
- `output/` - Generated Parquet files (gitignored)
