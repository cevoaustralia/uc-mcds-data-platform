# Glue ETL Scripts

PySpark scripts for Bronze → Silver → Gold transformations.

## Structure

- `common/` - Shared utilities (S3, logging, MCDS validator)
- `bronze/` - Landing → Bronze ingestion
- `silver/` - Bronze → Silver (MCDS transformations)
- `gold/` - Silver → Gold (analytics aggregations)
